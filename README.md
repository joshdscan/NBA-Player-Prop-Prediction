# NBA Player Prop Prediction Discovery

This repository focuses on exploring techniques for predicting **NBA player props**—such as total points scored—using both **machine learning algorithms** and **classic statistical methods** (e.g., regression models, time series analyses). Our goal is to approximate or outperform the lines set by oddsmakers using **open-source data** and domain-informed features.

---

## Key Highlights

- **Data Collection**  
  We gather publicly available data (e.g., NBA APIs, Kaggle datasets) to retrieve player performance logs and betting lines.

- **Feature Engineering**  
  We create **domain-specific features** such as rest days, rolling averages, and opponent matchups to capture nuances in player performance.

- **Model Exploration**  
  We combine **classic approaches** (ordinary least squares, Poisson regression) with **modern ML** (random forests, gradient boosting, neural nets, etc.) to find optimal predictive accuracy.  
  - **Metrics**: Emphasis on mean absolute percentage error (MAPE) for interpretability.

- **Continuous Discovery**  
  The repository encourages **further experimentation**—add new features, try advanced hyperparameter tuning, or use specialized statistical methods.
